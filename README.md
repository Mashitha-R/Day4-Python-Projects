# Message Generator ✨

A fun beginner Python project that prints motivational messages based on your **name **, **age**, and **birthday month**.  
It’s designed to encourage positivity while practicing coding basics like functions, conditions, and string handling.

## 🚀 Features
- Takes user input: name, age, and birthday month.
- Calculates name length and uses it in message logic.
- Prints uplifting messages like *“You are kind and brave!”*.
- Beginner-friendly structure with clear functions.
